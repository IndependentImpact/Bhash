InfoComm alignment module

IRI: https://hashgraphontology.xyz/alignment/infocomm

Maps Hedera/Hiero network elements to the Information Communication Ontology, modelling HCS message submission as communication events, mirror nodes as communication parties, and HAPI as the governing protocol.
